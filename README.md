# S M Montashir Ahmed — Portfolio

A modern responsive developer portfolio built with React + Vite.

## Run locally

1. Install Node.js (LTS recommended).
2. Open a terminal in this folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL shown by Vite.

## Customize

Edit `src/main.jsx` to replace the placeholder email, GitHub, LinkedIn, projects and resume link. Put your actual `resume.pdf` in the `public/` folder.

## Build

```bash
npm run build
```
